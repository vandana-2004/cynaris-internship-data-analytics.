# KPI Dashboard Narrative

## Overview

The KPI dashboard summarizes retail sales performance using total sales, total orders, and average order value. It also compares sales across regions and product categories.

## Key Insights

- **Total Sales:** Shows the overall sales value for the selected data.
- **Total Orders:** Shows the number of distinct orders.
- **Average Order Value:** Shows the average sales value per order.
- **Sales by Region:** Helps identify regions contributing to sales.
- **Sales by Category:** Helps compare sales across product categories.

## Interactive Filters

The Region and Category slicers allow users to filter the dashboard. The KPI cards and charts update when the selections change.

## Recommendations

- Review regional performance to identify areas needing attention.
- Compare category sales to support product planning.
- Monitor average order value alongside total sales.
- Review these KPIs regularly to track changes in performance.

## Data Limitations

The insights are based on the available dataset. No date-based analysis is included because a suitable date field was not available in the report.

## Conclusion

The dashboard provides a concise view of sales performance and allows users to explore results by region and category.
