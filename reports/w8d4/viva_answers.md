\# W8D4 – Viva Questions and Answers



\### 1. Explain what you built and the key decisions you made.



I built and deployed a FastAPI-based CIA Data Analyst application on Render. It supports CSV file uploads, AI-powered natural-language data queries, executive summaries, and PowerPoint report exports.



I also performed an exploratory analysis of the Indian Business dataset using Python and Pandas. I chose FastAPI for API development, Render for deployment, and Pandas for data analysis.



\### 2. What was the most challenging problem, and how did you solve it?



One of the main challenges was managing Python versions and dependency compatibility between the local development environment and production deployment.



I configured the deployment environment, adjusted dependencies, and tested the production endpoints. I verified the health check, CSV upload, AI query, executive summary, and PowerPoint export.



\### 3. If you had one more day, what would you improve?



I would add more automated tests, improve API security, introduce better error handling, and add interactive dashboards.



I would also improve monitoring and make the business insights easier for users to explore and understand.
